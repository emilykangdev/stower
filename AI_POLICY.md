# AI policy

Stower welcomes AI-assisted contributions under the following conditions.

- Contributors must fully review any AI-generated code before submitting.
- Contributors must understand the code they submit well enough to answer
  questions about it and explain the rationale behind decisions made.
- Commits whose changes were substantially AI-generated must include an
  `Assisted-by:` trailer in the commit message naming the tool (e.g.,
  `Assisted-by: Claude Code (claude-opus-4-8)`).
- AI agents must not respond directly to PR review comments or open issues.
  A human contributor is always in the loop.
- AI-generated security reports and AI-filed bug reports without human
  review will be closed without comment.

This policy is adapted from
https://github.com/hummingbird-project/hummingbird/blob/main/AI_POLICY.md.
