## Stower 0.2.2

### Under the hood

- Rotated the update-signing key used to verify app updates. If your copy of
  Stower doesn't offer this update automatically, download the latest version
  directly from [stower.app](https://stower.app).
- Debug and internal demo builds now keep fully separate local data from a
  real release install — internal hardening with no change to how the
  shipped app stores your data.
